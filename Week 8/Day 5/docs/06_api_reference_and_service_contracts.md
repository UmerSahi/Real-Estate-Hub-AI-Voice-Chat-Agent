## 1. Authentication & Common Headers

All production endpoints require standard authentication and content negotiation headers:
- `Content-Type: application/json`
- `Authorization: Bearer <API_TOKEN>`
- `X-Client-Version: 1.0.0`

## 2. Core REST Endpoints

### 2.1 Predict Fair Market Price
- **Path:** `POST /predict/price`
- **Description:** Returns point estimate, 10th/90th percentile bounds, and automated pricing verdict.

#### Request Payload:
```json
{
  "city": "Islamabad",
  "society": "DHA Phase 2",
  "property_type": "House",
  "area_marla": 10.0,
  "bedrooms": 4,
  "bathrooms": 4,
  "has_corner": true,
  "facing_park": false,
  "main_boulevard": false,
  "quoted_price_pkr": 38000000.0
}
```

#### Response (HTTP 200 OK):
```json
{
  "property_id": "prop_99182",
  "predicted_price_pkr": 34500000.0,
  "predicted_price_lac": 345.0,
  "predicted_price_crore": 3.45,
  "formatted_price": "3.45 Crore PKR",
  "confidence_interval_80pct": {
    "lower_bound_pkr": 31500000.0,
    "lower_bound_crore": 3.15,
    "upper_bound_pkr": 37200000.0,
    "upper_bound_crore": 3.72
  },
  "pricing_verdict": {
    "status": "OVERPRICED",
    "percentage_deviation": 10.14,

  },
  "requires_human_appraisal": false,
  "disclaimer": "This valuation is an algorithmic statistical estimate generated by machine learning and does not constitute a certified physical bank appraisal."
}
```

### 2.4 Telephony Webhook Ingestion
- **Path:** `POST /integration/voice-call`
- **Description:** Ingests post-call event payloads from Vapi or Deepgram. Auto-triggers VIP Email Dispatcher if score $\ge 0.65$.

```bash
curl -X POST "http://localhost:8000/integration/voice-call" \
  -H "Content-Type: application/json" \
  -d '{
    "call_id": "call_vapi_9921",
    "customer_phone": "+923001234567",
    "call_duration_seconds": 260,
    "stated_budget_pkr": 35000000,
    "site_visit_booked": true,
    "target_city": "Islamabad",
    "target_society": "Bahria Town Phase 7",
    "transcript_summary": "Customer looking for 10 Marla ready house in Bahria Phase 7 with immediate token."
  }'
```

### 2.5 LangGraph Copilot Dialogue
- **Path:** `POST /agent/chat`
- **Description:** Stateful multi-turn chat in UrduLish with strict tool grounding.

```bash
curl -X POST "http://localhost:8000/agent/chat" \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "sess_882",
    "message": "DHA Phase 5 Lahore mein 1 Kanal plot ki fair price kya chal rahi hai?"
  }'
```

#### Response (HTTP 200 OK):
```json
{
  "session_id": "sess_882",
  "reply": "DHA Phase 5 Lahore mein 1 Kanal plot ki fair price taqreeban 4.25 Crore PKR hai (range: 3.90 se 4.60 Crore PKR).",
  "tools_invoked": ["predict_property_price"],
  "grounded_verification": true
}
```
