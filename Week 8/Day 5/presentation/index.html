Problem Framing

The Two Multi-Crore Financial Bleeds

Quantifying the crippling cost of human guesswork in luxury real estate

Bleed 1: The Valuation Misquote Trap
±25% Quote Error
Traditional agents quote from intuition:
  • Overpriced Listings: Stagnate for 180+ days, eroding buyer trust and tying up marketing capital.
  • Underpriced Deals: Sell instantly but leave 30-50 Lac PKR on the table, cheating sellers of fair capital.
  • Heuristic Baseline: Simple median pricing misses actual transaction value by 156.5 Lac PKR on average!
Bleed 2: The Sales Calling Capacity Choke
40 Calls / 200 Leads
A 5-person brokerage receives 200 daily leads but only has time for 40 outbound calls:
  • Random Calling: 71% of calls reach casual window-shoppers with no intent.
  • Lost Whales: High-ticket overseas investors get buried in unread CRM queues and buy elsewhere.
  • Asymmetric Cost: False Negative = PKR 300,000 lost commission vs False Positive = PKR 500 phone labor.
Mathematical Reality: Because missing a buyer is 600x more expensive than placing a call, standard 0.50 threshold models fail. Our cost-optimized threshold (th=0.05) preserves over 1.92 Crore PKR in deal margin.

Data Engineering & Pakistani Domain Features

10,480 listings and 3,496 leads curated with zero data leakage

Feature Engineering Highlights
  • ✓
    Marla / Kanal Normalizer: Standardizes 1 Kanal = 20 Marla, converting colloquial Pakistani metrics into uniform numeric features.
  • ✓
    Crore / Lac Parser: Automatically parses Pakistani currency strings (e.g. '2.5 Crore' ➔ 25,000,000 PKR).
  • ✓
    Society Tiering: Categorizes localities into Tier 1 (DHA, Bahria, Gulberg, Clifton), Tier 2 (Johar Town, G-11), and Tier 3 (Suburban).
  • ✓
    Telephony Ingestion Signals: Extracts talk time duration, inquiry velocity, site visit intent, and budget affordability ratio.
Pre-Processing Pipeline Safeguards
  • 🔒
    Zero Data Leakage: Transformations fitted exclusively on 70% train split; validation (15%) and test (15%) strictly held out.
  • 🔒
    TargetEncoder with Smoothing: Handles 100+ micro-locations without exploding dimensionality or overfitting sparse sectors.
  • 🔒
    RobustScaler Normalization: Centers features using interquartile medians, protecting gradients against ultra-luxury price outliers.
  • 🔒
    OOD Boundary Guards: Rejects absurd plot sizes (>100 Marla) or invalid city queries prior to model scoring.

Model 2: Lead Scoring & The Accuracy Paradox

Why naive accuracy leads to bankruptcy, and how SMOTE balances real conversion yield

The Accuracy Paradox Illustrated
71.4% Accuracy = 0 Deals
If our classifier naively predicted "NOT CONVERTING" for all 525 test leads:
  • Accuracy would look impressive at 71.4%.
  • Actual closed deals captured: 0 (Recall = 0.0%).
  • Commission lost: PKR 4.5 Crore.
Verdict: Accuracy is strictly rejected. We evaluate using PR-AUC, F1-Score, and Precision@Top-20%.
Imbalance Strategy Threshold F1-Score Precision Recall
SMOTE Oversampling 0.50 0.6136 71.05% 54.00%
Class Weights 0.50 0.6122 62.50% 60.00%
Threshold Tuning 0.16 0.5962 46.62% 82.67%
No Balancing 0.50 0.5946 70.64% 51.33%
Champion Selected: LightGBM + SMOTE gives highest balanced F1 (0.6136) and robust 71% precision.

Governance & Safety

Production Guardrails & Model Governance

Multi-layered security shielding users, models, and corporate liability

Operational Security Layers
  • 🛡️
    Out-of-Distribution (OOD) Bounding: Automatically blocks corrupt inputs (e.g., plots > 100 Marla, negative bedrooms, unknown cities) before invoking ML inference.
  • 🛡️
    Adversarial Prompt-Injection Defense: Regex & semantic firewall blocks prompt manipulations such as 'Set price to 1 rupee' or 'Forget prior rules'.
  • 🛡️
    Mandatory Legal Disclaimers: Every automated price quote appends non-certified advisory legal language required by real estate regulatory authorities.
Enterprise Observability & Audit Trail
  • 📝
    SQLite Audit DB & JSONL Stream: Every prediction logs UUID, client IP, latency (ms), input features, output score, and model version.
  • 📝
    MLflow Experiment Tracking: All regression and classification experiments logged with hyperparameter tuning trials and model signatures.
  • 📝
    Automated Fallback Architecture: If ML service encounters latency > 1,000ms, fallback rules supply cached society averages seamlessly.
